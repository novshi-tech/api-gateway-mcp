# 0018 1 人のユーザが複数の組織（テナント）にまたがる対応はしない。組織の切り替えはスタンドで行う

- 状態: 採用（2026-10-22、直樹の結論）。0017（論点のメモ）はこれで閉じる
  **2026-10-23: 0020 で単位を一般化した。この ADR の「組織（テナント）」は、0020 の「チーム」（1 つのデプロイ）と読む。決定 1〜3 はそのまま。1 人が複数のチームに属する問題の個人の側からの解き方（個人の Murmur）は 0022 の構想。背景と帰結の会社ごとの事情は経緯として残す**
- 関連: 0017（複数の組織にまたがる認証と接続の論点）、0003（ゲートウェイから伝搬されるユーザー識別。1 つの発行者だけを信頼する）、0006（1 のアカウントリンクは採らない）、0013（テナント境界は秘匿の境界）、0016（次の段階。「段階 5 に入る前に決めること」のログインの節）

## 背景

直樹は 2 社（UBS: Microsoft Entra、ノブシテック: Google Workspace）を経営し、顧客の環境でも作業する。
ゲートウェイ（api-gateway-mcp）は 1 つのデプロイに IdP が 1 つで、資格情報はサインインしたユーザごとに登録され、ラベルで組織を見分けているだけ。テナントの概念はない。
Murmur の User はゲートウェイのサインインの ID と 1 対 1（0003）。
「1 人が複数の組織にまたがる」「組織ごとに IdP が違う」をどう扱うかを 0017 に論点として書き残し、設計は次のステップとしていた。

## 決定（直樹、2026-10-22）

1. **1 人のユーザが複数の組織（テナント）にまたがる対応（1 ユーザマルチテナント）は、Murmur とゲートウェイではやらない。**
   理由: どうやっても適切なセキュリティ境界を引けない。
   1 人のユーザに複数の組織の資格情報とデータを束ねると、組織の境界はそのユーザの自己申告（ラベル・切り替え）にしかならず、ゲートウェイも Murmur も強制できない。
2. ゲートウェイが複数のユーザに同時にログインして切り替えられるようになるのはよいかもしれない。ただし、**MCP に同時に接続できるのは 1 テナントだけ。**
3. **複数の組織を使い分けるなら、スタンド（Claude Code）の側で切り替える。** たとえば `settings.json` で claude.ai の公式コネクタを切り、ローカルで別の MCP（別の組織のゲートウェイ）をつなぐ。
   Murmur とゲートウェイは「1 つの接続 = 1 つの組織」を前提にしてよい。

## 帰結

- 0017 の「設計で答えること」1〜6 はこの決定で閉じる。0017 の候補のうち「1 つのゲートウェイを複数の IdP に対応させ、アカウントリンク（0006 の 1）を足す」は採らない。0006 の 1（アカウントリンク）は本番でも入れない
- ゲートウェイは 1 つのデプロイに IdP が 1 つのまま。Murmur は 1 つのゲートウェイの JWKS だけを信頼する（0003 のまま）。発行者ごとに JWKS とテナントを対応させる仕組みは足さない
- テナント境界は秘匿の境界（0013）のまま。それを 1 人のユーザの中で跨がせる仕組み（組織をまたぐ Viewer、組織をまたぐ結び候補）を本体に足さない
- 別の組織（別の IdP）を使うときは、その組織のゲートウェイ（と Murmur）を別に立て、スタンドの接続先を切り替える。本体にもゲートウェイにも、組織の切り替えの仕組みは足さない
- スタンド側の切り替えの手順は `docs/stand/connect.md` に書く（Claude Code。Cowork は claude.ai のコネクタが 1 つなので、1 つの組織に固定）
- 0016 の段取り 1〜4 は今の構成（UBS の Entra。直樹と木村さん）で進められる。
- **0016 の最初のデータソースは UBS 側にする（2026-10-22、直樹）。** UBS は独自に Claude の Team プランを契約しているので、スタンド・ゲートウェイ・Murmur が UBS の中で自然に分離できる。
  今の UBS の Murmur には UBS のテナントだけを入れ、ノブシテックのテナントは入れない（Gmail = ノブシテックは、やるなら別のゲートウェイと Murmur で）

## この ADR での言葉

- **組織（テナント）**: IdP を 1 つ持つ単位。ゲートウェイの 1 つのデプロイに対応する（UBS の Entra、ノブシテックの Google Workspace）
- **スタンド**: Cowork / Claude Code。Murmur とゲートウェイを MCP 経由で呼ぶ側
