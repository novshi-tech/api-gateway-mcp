# 0011 設計の正本をこのリポジトリに移す

- 状態: 採用（2026-10-17、直樹の指示）
- 関連: 0008、0009、0010

## 背景

これまでは Google Doc（設計メモ「AIネイティブ タスク管理ツール」と、プロトタイプ計画）が設計の正本で、`docs/PLAN.md` はその書き出しだった。
食い違ったら Google Doc が優先し、プロトタイプで得た知見はステップ 7 で Google Doc に書き戻す約束だった。

0009・0010 で、リストの構成とデータモデルを組み替えることにした。Google Doc の内容と大きく食い違うので、
Google Doc を先に直すか、リポジトリの側を正にするかを決める必要があった。

## 決定

- 設計の正本は、このリポジトリのドキュメント（`docs/PLAN.md` と `docs/adr/`）にする
- Google Doc は格下げし、2026-10-17 までの経緯の資料として残す。今後は更新しない。リポジトリと食い違ったらリポジトリが優先
- 計画の「Google Doc への書き戻し」はなくなる。振り返りのステップでは、設計メモの未決リストへの判定を `docs/` に書く
- v1 の計画と実装は、タグ `proto-v1` で参照できる（`v*` のタグは CI が prod にデプロイするので、別の名前にした）

## 影響

- `CLAUDE.md` の「設計の正本」と、ADR の「Google Doc への書き戻しを判断する」の記述を直した
- `docs/PLAN.md` は v2 として書き直した（0009・0010 の形）
